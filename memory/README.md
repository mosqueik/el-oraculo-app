# 🧠 Memory — El Oráculo App

Esta carpeta contiene la memoria del proyecto `el-oraculo-app`.

---

## 📋 CÓMO USAR ESTA MEMORIA

### Al inicio de cada sesión:
1. Lee `memory/PROJECT_STATE.md` → Estado actual del proyecto
2. Lee `memory/SESSION_LOG.md` → Historial de sesiones
3. Lee `docs/TODO.md` → Qué falta hacer

### Al final de cada sesión:
1. Actualiza `memory/SESSION_LOG.md` con lo que se hizo
2. Actualiza `memory/LEARNING_LOG.md` con aprendizajes
3. Actualiza `memory/PROJECT_STATE.md` si cambió el estado

---

## 📁 ARCHIVOS

| Archivo | Propósito | Actualizar |
|---------|-----------|:----------:|
| `PROJECT_STATE.md` | Estado actual del proyecto | Al cambiar fase/estado |
| `SESSION_LOG.md` | Historial de sesiones | Al final de cada sesión |
| `LEARNING_LOG.md` | Aprendizajes y decisiones | Cuando haya algo nuevo |
| `KNOWLEDGE_ARCHITECTURE.md` | Conocimiento técnico | Cuando cambie la arquitectura |

---

## ⚠️ IMPORTANTE

**Esta memoria es SEPARADA del bot de n8n.**

| Proyecto | Memoria |
|----------|---------|

# 🪙 El Oráculo — Crypto Trading Bot

> AI-powered crypto trading bot with React Native mobile app

## Architecture

```
el-oraculo-app/
├── backend/     # Node.js trading engine
├── mobile/      # React Native mobile app
└── shared/      # Shared types, constants, utils
```

## Quick Start

```bash
# Install dependencies
npm install

# Run backend
npm run dev:backend

# Run mobile
npm run dev:mobile
```

## Tech Stack

- **Backend:** Node.js, Express, Binance API, technicalindicators
- **Mobile:** React Native, Expo, React Navigation
- **Shared:** TypeScript types and constants
